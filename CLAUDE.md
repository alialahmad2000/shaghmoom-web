# Shoghmoum website — project brief for Claude

Official site of **شركة شغموم للمقاولات العامة** (Shoghmoum General Contracting),
a structure-and-finishing contractor in Al-Madinah. Owner and main developer:
**Khaled Al-Omari**, who speaks Arabic. Talk to him in Arabic and explain changes
in plain words, not code.

Live at **https://shoghmoum.com** (Arabic only, `/ar/...`).

## How a change reaches the site

- `main` **is** production. A push to `main` builds on Vercel and is live on
  shoghmoum.com in about a minute. There is no review gate.
- Before pushing: `npm run build` must pass (it also type-checks), and `npm run lint`.
- After pushing: open https://shoghmoum.com/ar and the page you changed, and confirm
  the change is actually there.
- For anything bigger than a text edit, work on a branch first. Vercel builds a
  preview for every branch, but previews need a Vercel login to view.
- **Undo:** Vercel dashboard → Deployments → the last good one → "Instant Rollback"
  (seconds), then `git revert` the bad commit so `main` matches.
- The git commit author's e-mail must belong to a member of the Vercel account,
  or Vercel refuses to deploy the commit ("not a member of the team").

## Brand rules (do not break)

- Palette: maroon `#441420`, sand `#E9EAD9`, terracotta `#814B41` (on sand only),
  gold `#AA8302` (one highlight per screen). No other colours.
- Font: IBM Plex Sans Arabic 400/500/600, self-hosted in `app/fonts/`.
- Slogan: «نرى ما لم يُرسَم.. ونُتقن ما لا يُرى». The old «العُشر» idea is retired;
  never bring it back.
- Voice: formal, calm Arabic. No hype, no emojis, no exclamation marks, no discounts.
- Arabic-Indic numerals in Arabic copy; Latin digits only in phone numbers and links.
- Never add a licence, membership, accreditation or registration claim unless the
  owner has the document for it.
- RTL: use logical properties (`ms-`, `pe-`, `start`, `end`), not left/right.

## Gotchas

- This is Next.js 16: read `node_modules/next/dist/docs/` before using an API you
  are unsure of (see AGENTS.md).
- A static `opengraph-image.png` inside `app/[locale]/` breaks the Vercel build;
  the share image is generated by script into `public/`.
- In zsh, never name a loop variable `path` (it is `PATH`).
- Hero images are `public/images/hero/site-wide.jpg` (1920×1080) and
  `site-tall.jpg` (1080×1920).

## Domains and DNS

- **shoghmoum.com** is registered at GoDaddy (owner's account). DNS: `A @ → 76.76.21.21`
  (Vercel). The MX, Outlook/Microsoft 365 and TXT records are the company e-mail:
  do not touch them.
- **www.shoghmoum.com**, **shaghmoom.com** and **www.shaghmoom.com** all redirect
  (308) to shoghmoum.com, path kept. These redirects are set in the Vercel project's
  Domains settings, not in code. shaghmoom.com's DNS is on Cloudflare (two A records
  → 76.76.21.21, grey cloud / DNS only; proxying breaks Vercel's certificate).
- GoDaddy's DNS editor fails with `genericErrorMessage` when the site language is
  Arabic: switch GoDaddy to English (market en-US) first. Saving asks for a code
  from the GoDaddy app.

## The quote form

Requests go to `/api/lead`. A request counts as received only when it was e-mailed
(Resend) or stored (Supabase). Neither is configured yet, so the form hands the
visitor to WhatsApp with everything they typed already in the message. To get
e-mail notifications: a Resend account, the sending domain verified there (DNS
records in GoDaddy), and `RESEND_API_KEY` in Vercel (Production). Optional:
`LEAD_NOTIFY_TO`, `LEAD_FROM`. See README "Environment variables".
